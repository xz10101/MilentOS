# MilentOS
MilentOS - это легковесная операционная система для ПК на процессорах i386(x32)

## Быстрый старт, сборка, и установка софта
#### Первый этап - установка ПО
Установите данное ПО введя в терминал команду в зависимости от вашего дистрибутива:
```bash
# Debian/Ubuntu
sudo apt update && sudo apt install git make qemu ld

# Arch/Arch-based
sudo pacman -Syu && sudo pacman -S git make qemu ld

# Void/Void-based
sudo xbps-install -Syu && sudo xbps-install git make qemu ld

# Gentoo/Gentoo-based
sudo emerge --ask git make qemu ld
```
Если у вас Windows 10/11 используйте Windows-Subsystem-For-Linux (WSL) или MSYS2

## Второй этап, компиляция
Для начала компиляции вам нужно скачать репозиторий
```bash 
git clone https://github.com/xz10101/MilentOS
cd MilentOS
```
Начните компиляцию:
```bash
make run
```
В случае ошибок во время сборки обратитесь в тему для вопросов...

После сборки у вас запустится виртуальная машина qemu и запустит ОС

# FAQ (Чаво)
### ***Почему ОС такая простая?***
Операционная система пишется с полного нуля, имеет свою структуру исходных файлов. Добавить файловую систему, поддержку приложений и большинство вещей очень тяжело (да и кому такая ос понадобится если есть дистрибутивы linux и windows)

### ***Когда выходят обновления и скоро ли будет полноценная рабочая ОС?***
Обновления будут выходить ВСЕГДА по разному, ведь разработчик пока что один (и это я), и неизвестно когда выйдет полноценный рабочий билд системы, так что только ждать!
